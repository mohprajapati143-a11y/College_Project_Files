# 🌐 Frontend Development & Client-Side Scripting (HTML/CSS/JS)

Welcome to the **HTML, CSS, and JavaScript** laboratory section. This directory contains academic and conceptual exercises designed to teach and demonstrate the structure of web documents, the styling of elements, document navigation, and interactive client-side logic using JavaScript.

These exercises are structured from fundamental markup tags up to multi-functional frontend components.

---

## 🔍 Key Concepts Covered

1. **Semantic HTML**: Structuring documents logically using proper elements to ensure accessibility and clear syntax.
2. **Cascading Style Sheets (CSS)**: Transitioning from raw structure to styling, including color palettes, padding/margin spacing, block alignment, and referencing external style architectures.
3. **Event-Driven JavaScript**: Responding to button clicks (`onclick`), capturing user input values, running logical operations, and updating the page text dynamically (DOM manipulation).
4. **Interactive Hotspots**: Implementing Image Maps where different parts of a single graphic link to distinct targets.

## 🚀 How to Run and Test

Since these files are compiled entirely of client-side HTML, CSS, and JavaScript, they require **no backend server setup**.

### Open in Web Browser
1. Open your file explorer and navigate to this directory (`College_Project_Files/HTML/`).
2. Double-click any `.html` file (e.g., `Simple Calculator.html`).
3. The file will open directly in your default web browser (Chrome, Edge, Firefox, Safari, etc.).
4. For interactive files, enter inputs in the designated text boxes or press buttons to trigger JavaScript alerts or DOM updates.
